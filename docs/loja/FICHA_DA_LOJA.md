## Google Play – Segurança dos dados

| Pergunta | Resposta |
|---|---|
| Coleta ou compartilha dados? | **Sim** |
| Dados criptografados em trânsito? | **Sim** (HTTPS/Firebase) |
| Usuário pode pedir exclusão? | **Sim** (pelo chat de suporte; dados do multiplayer são apagados ao fim da sala) |

Tipos de dados **coletados** (nenhum é "compartilhado": Firebase e Crisp são operadores):

| Categoria › Tipo | Finalidade | Opcional? |
|---|---|---|
| Atividade no app › Interações no app | Análise | Não |
| Info e desempenho do app › Registros de falhas | Análise | Não |
| Info e desempenho do app › Diagnóstico | Análise | Não |
| Identificadores do dispositivo ou outros › (ID anônimo do Firebase) | Funcionalidade do app (multiplayer), Análise | Não |
| Info pessoal › Outras informações (apelido do multiplayer) | Funcionalidade do app | **Sim** |
| Mensagens › Outras mensagens no app (chat de suporte) | Suporte ao usuário (Funcionalidade) | **Sim** |

Fotos do quebra-cabeça: **não declarar**. Elas não saem do aparelho.

## App Store – Privacidade do app

"Dados usados para rastrear você": **Nenhum**.

"Dados vinculados a você": **Nenhum** (sem conta/login real).

"Dados não vinculados a você":
- **Uso** › Interação com o produto → Análise
- **Diagnóstico** › Dados de falhas, Dados de desempenho → Funcionalidade do app
- **Identificadores** › ID do usuário (anônimo do Firebase) → Funcionalidade do app
- **Conteúdo do usuário** › Outro conteúdo do usuário (apelido) → Funcionalidade do app
- **Conteúdo do usuário** › Atendimento ao cliente (chat) → Funcionalidade do app

## Classificação de conteúdo
Questionário IARC (Play) e Apple: responda **Não** para violência, sexo, linguagem imprópria, drogas, jogos de azar e terror.
- "Usuários podem interagir/trocar conteúdo?" → **Sim, de forma limitada**: só apelidos (filtrados contra palavras impróprias); não há chat entre jogadores.
- "Referências religiosas" (se perguntado) → conteúdo educativo bíblico.
- Resultado esperado: **Livre / 4+**.

## Público-alvo (Play)
Faixas: **13–15, 16–17, 18+**. Não marque faixas abaixo de 13, para não entrar no programa Families.
"O app pode atrair crianças sem querer?" → Sim, mas não é voltado a elas. O app não tem anúncios e o multiplayer usa só apelido.
