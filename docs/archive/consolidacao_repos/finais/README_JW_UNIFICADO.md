# JW Project Unificado

Este indice unifica o contexto dos projetos JW para concentrar revisao e proxima execucao no AppAndroid.

## Escopo consolidado

- AppAndroid: app Flutter principal para testes e publicacao Android
- JWQuizFlutter: espelho historico do app Flutter (conteudo majoritariamente duplicado)
- JW-Quiz: versao web/PWA original, com documentos tecnicos uteis
- JWQuizAndroid: repositorio placeholder (README minimo)

## Decisao de consolidacao

- Base oficial para app movel: AppAndroid
- Documentacao tecnica web que continua relevante: manter como referencia em docs/jw_unificado/unificados/JW-Quiz
- Duplicados exatos removidos da revisao
- Conflitos de mesmo nome resolvidos nesta pasta finais

## Resumo funcional do projeto

- Quiz biblico com base de perguntas extensa
- Minigames e sistema de conquistas
- Multiplayer e internacionalizacao na versao Flutter
- Versao web/PWA com painel administrativo e operacao via navegador

1. Comece por CONSOLIDACAO_MD_JW.md
